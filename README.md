# Enhanced Portfolio with GSAP Animations

### ✨ GSAP Animations
- **Intro Sequence**: Smooth, staggered animations for all intro elements
- **Scroll Animations**: Elements animate in as you scroll through sections
- **Interactive Hover Effects**: Enhanced button and card interactions
- **Typewriter Effect**: Animated text typing for the website URL
- **Counter Animations**: Smooth number counting in stats

All animations can be customized by modifying the GSAP timelines in `script.js`. Colors, durations, and easing functions are easily adjustable.
